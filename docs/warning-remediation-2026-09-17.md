## 적용 내용

- 컨테이너 메모리 판정: 원시 cgroup 사용량에서 Docker가 제공하는 `inactive_file`(v1은 `total_inactive_file`)만 뺀 사용량을 사용한다. 원시 사용량, 캐시, 보정 사용량을 모두 보존하고 화면에도 구분한다. 캐시 정보가 없거나 잘못된 경우 원시 값으로 판정한다. OOM·비정상 health·재시작 경고는 유지한다.

- 제한된 프로세스/systemd 관측은 전체 위험 집계와 별도의 중립 안내로 표시한다. 해당 제한에 정확히 대응하는 `no_data` 규칙도 중복 집계하지 않지만, 규칙 상세의 원래 상태는 보존한다. 권한 오류·수집 오류·잘린 수집·미확인 대상·열린 장애는 계속 경고한다.
- 성공한 HTTP 검사의 단순 지연은 주의로 표시한다. 실제 DNS/TLS/timeout/HTTP 실패는 위험 판정을 유지한다.
- 배포본에 누락됐던 Pongdang 컨테이너 이름/프로젝트 매핑을 추가했다. 다른 프로젝트를 가장한 데이터는 계속 거부한다.
